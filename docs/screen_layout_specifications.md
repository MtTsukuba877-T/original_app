## 実装時の注意事項

### Tailwind CSSでのレスポンシブ実装

受検者向け画面と共通画面は、モバイルファースト設計です。Tailwind CSSでは以下のような書き方になります。

```html
<div class="text-2xl md:text-4xl lg:text-6xl">
  タイトル
</div>
```

**解説**:
- `text-2xl`: スマホ用の基本サイズ(24px程度)
- `md:text-4xl`: タブレット以上(768px以上)で36px程度
- `lg:text-6xl`: PC以上(1024px以上)で60px程度

### カスタムカラーの設定

Tailwindのボトルグリーン(#0B6623)や受検者向け画面の明るい青(#4A90E2)を正確に再現したい場合、app/assets/tailwind/application.cssにカスタムカラーを追加する必要があります。

```css
@import "tailwindcss";

@theme {
  /* ヘッダー背景(システム管理者・企業担当者) */
  --color-bottle-green: #0B6623;

  /* 主要ボタン(登録する、更新する、編集する) */
  --color-primary-green: #159827;

  /* ヘッダー背景(受検者) */
  --color-employee-navy: #01336E;

  /* 受検者向け画面の主要ボタン(次へ、ログインする、送信する) */
  --color-employee-blue: #4A90E2;
}
```

その後、`bg-bottle-green`、`bg-employee-blue`、`bg-primary-green`のように使えます。
