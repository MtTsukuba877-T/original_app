## 4. 削減の主要ポイント

### Phase 2: システム管理者機能（−3 SP）

- 企業一覧画面の検索機能を削減
- 企業情報登録はrails console対応、招待メール送信は簡素な画面
- 企業編集画面は本リリース版に回す

### Phase 3: 企業担当者機能（−6 SP）

- 実施回編集機能を削除（本リリース版）
- CSVヘッダー行対応を削除（本リリース版）
- 名簿の個別追加機能を削除（CSVアップロードに統一）
- 進捗確認画面を統合（未ログイン者+未受検者）

### Phase 4: メール配信（−10 SP）

- LINE連携を完全に削除
- メール配信で代替（Action Mailer + letter_opener_web）
- 本リリース版でLINE連携を追加予定

### Phase 7: 品質向上（優先度管理）

- 「必ず実装（高）」「余裕があれば（中）」「本リリース版で対応可（低）」に分類
- MVPリリースまでに最低15 SP（高）は実装
- 時間があれば12 SP（中）を追加実装
